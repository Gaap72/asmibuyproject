## Comportamiento antes y después
| Caso | Antes | Después |
| --- | --- | --- |
| Error sin datos previos | `console.error`; estado vacío falso «No se encontraron insumos…» | Bloque de error con mensaje y «Reintentar»; no aparece el estado vacío |
| Error con datos previos | Datos viejos sin ningún indicio | Datos previos se conservan; el bloque de error añade «Se muestran los datos de la última consulta correcta (hh:mm).» |
| Recarga al volver a la pestaña (`visibilitychange`, `focus`) | Error silencioso | Mismo manejo; si ya hay una consulta en curso no lanza otra |
| Reintento | No existía | «Reintentar» llama a `recargarAvisos()`; en éxito el error desaparece y se muestra «Actualizado hh:mm» |

Mensajes: `status 0` → «No se pudo conectar con el servidor.»; 401 o 403 → «Tu sesión no permite consultar los avisos.»; otros → «No se pudieron consultar los avisos.».
