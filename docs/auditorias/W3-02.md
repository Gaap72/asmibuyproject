## Hallazgos y revisión

1. **Inmutabilidad de Promociones Retiradas:** Se garantizó a nivel de servicio y repositorio que el estado `RETIRADA` sea terminal; se lanza `ErrorPromocion` HTTP 400 (`PROMOCION_RETIRADA`) si se intenta modificar o reactivar.
2. **Validaciones de Parámetros:** Se restringe $N > M \ge 1$ para NxM y $0 < \text{porcentaje} \le 100$ para Porcentaje.
